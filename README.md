# Daily Compass

Crie um aplicativo mobile completo (iOS/Android) de assinatura com foco em desenvolvimento espiritual prático e uso diário, baseado em conexão com Deus, controle emocional e direção na vida.

O app NÃO deve ser apenas um devocional ou leitura bíblica. Ele deve funcionar como um sistema inteligente de evolução diária, que ajuda o usuário a aplicar ensinamentos na vida real e acompanhar seu progresso ao longo do tempo.

OBJETIVO PRINCIPAL:
Criar um aplicativo que o usuário utilize TODOS OS DIAS, por meses ou anos, sentindo evolução constante, clareza emocional e direção prática para a vida.

🔵 CONCEITO DO PRODUTO

O app deve ser posicionado como:
“Um guia diário prático para viver com mais paz, clareza e direção com Deus”

NÃO deve parecer religioso pesado, nem doutrinador.
Deve ser leve, acessível, emocional e aplicável.

🟢 ESTRUTURA PRINCIPAL DO APP

Criar as seguintes abas principais:

Home (Momento com Deus)

Situações (Ajuda imediata)

Evolução (Progresso do usuário)

Planos (Jornadas guiadas)

Áudios (Controle emocional)

Perfil

🟡 1. HOME — MOMENTO DIÁRIO

Elemento principal do app.

Cada dia deve conter:

Versículo curto

Explicação simples (linguagem moderna)

Aplicação prática do dia

Ação concreta (ex: “hoje, evite reagir no impulso”)

Oração curta

IMPORTANTE:
Cada dia deve ser único, não repetir conteúdo.

🟠 2. SITUAÇÕES (BOTÃO DE AJUDA IMEDIATA)

Criar um sistema interativo onde o usuário escolhe como está se sentindo:

Exemplos:

Ansioso

Confuso

Com medo

Triste

Sem direção

Com raiva

O app deve responder com:

Direção espiritual prática

Reflexão

Ação recomendada

Versículo relacionado

Esse módulo deve parecer um “aconselhamento em tempo real”.

🔵 3. EVOLUÇÃO (SISTEMA DE PROGRESSO)

Criar sistema visual de evolução:

Dias consecutivos (streak)

Progresso em planos

Níveis (iniciante → equilíbrio → clareza → confiança)

Mostrar claramente que o usuário está evoluindo.

🟣 4. PLANOS (JORNADAS GUIADAS)

Criar jornadas estruturadas:

7 dias para acalmar a mente

14 dias para controle emocional

21 dias para fortalecer a fé

30 dias para viver com mais paz

Cada plano com:

sequência lógica

evolução progressiva

conteúdo exclusivo

🔴 5. ÁUDIOS GUIADOS

Criar biblioteca de áudios:

ansiedade

calma

confiança

entrega

descanso mental

Formato:
curtos (2 a 5 minutos), para uso diário.

🟤 6. CHECK-IN DIÁRIO

Antes do conteúdo do dia, perguntar:

“Como você está hoje?”

Baseado na resposta, adaptar conteúdo.

⚫ PERSONALIZAÇÃO

No onboarding, perguntar:

objetivo (paz, clareza, ansiedade, fé)

frequência desejada

Usar isso para adaptar experiência.

🟢 SISTEMA DE CONTEÚDO DINÂMICO

Criar grande base de conteúdos variáveis.

Evitar repetição.

Usar:

categorias

rotação inteligente

variações de linguagem

🟡 NOTIFICAÇÕES INTELIGENTES

Exemplos:

“Seu momento com Deus hoje já está pronto”

“Respire. Você não precisa reagir agora”

“Hoje é um bom dia para agir com calma”

🟣 UX/UI (DESIGN)

minimalista

acolhedor

cores suaves

foco em calma e clareza

fácil navegação

🔴 MONETIZAÇÃO

Modelo de assinatura:

7 dias grátis

R$29,90 ou R$39,90/mês

Plano free limitado:

acesso parcial

Plano premium:

acesso total

🧠 DIFERENCIAL (OBRIGATÓRIO)

O app deve:

focar em AÇÃO (não só leitura)

ajudar em decisões reais

criar hábito diário

gerar evolução perceptível

💣 OBJETIVO FINAL

Criar um aplicativo que o usuário pense:

“Eu preciso disso todos os dias”

e não apenas:

“vou usar de vez em quando”

Crie toda a estrutura do app, fluxos de navegação, lógica de conteúdo, telas, UX e sistema de retenção baseado nesses princípios.
